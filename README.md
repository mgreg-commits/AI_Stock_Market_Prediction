# AI_Stock_Market_Prediction
School project employing machine learning techniques to produce a trading agent that uses techncal indicators that trade.

When running the agent, you can switch between a single stock view and a portfolio stock view. You can pick a data range starting anywhere from the last 25 years to the current date (4/1/2025). If you want to run the agent past this day you will need to download the new data. 

I used AlphaVantage for the data so if you would like to run the model you will need to aquire an API key to download the most up to date data. Note: they do have API limits for the free accounts.
